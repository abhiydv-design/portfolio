# Abhishek, portfolio

Static site, deployed on Vercel from `main`. Every push goes live in about 30 seconds.

- `content.json`: all the words on the site (name, intro, projects, about, links).
- `build.py`: turns `content.json` into `index.html` and `work/*.html`. Run `python3 build.py` after editing content.
- `assets/patterns.js`: the pixel and halftone graphics (hero flower, project patterns, footer band).
- `assets/styles.css`: layout and type. Palette: Electric Blue (#315BEF, #2146C7, #8EA4FF, #F7F7F2, #111111).
